# ABC Tracing Alphabet (Android, Kotlin)

An educational Android app designed for toddlers learning how to trace letters.  
Built using **Kotlin**, **Android Studio**, and custom drawing logic.

## ✨ Features
- Full alphabet tracing (Aa–Zz)
- Custom `TracingView` for finger drawing
- XML-based UI layout
- High-contrast tracing guides
- Works on tablets and phones
- Offline and lightweight

## 🔧 How It Works
The app loads a tracing image (Aa–Zz) and overlays a custom drawing canvas.  
Users trace the letter using touch events.
